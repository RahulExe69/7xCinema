# Glossary

- **Adapter:** Provider-specific code that implements the common integration contract.
- **Audio track:** An audio stream inside a specific media asset that may be selectable by the player.
- **Canonical title:** An internal logical identity used to group source records believed to represent the same work.
- **Catalogue:** The user-facing collection of movies, series, seasons, and episodes.
- **Deduplication:** Grouping matching records while preserving each original source record.
- **Dubbed version:** A separate media asset with its own audio language, not necessarily a track inside another file.
- **Evidence level:** How a metadata claim is known: verified, provider claim, inferred, or unknown.
- **External subtitle:** A separate subtitle resource loaded alongside a media asset.
- **Partial results:** Useful results returned even though one or more providers are still loading, timed out, or failed.
- **Provider:** An independently operated data/content integration.
- **Provider health:** Observed search/detail/resolve availability and performance; not a guarantee that every stream plays.
- **Provenance:** Information about the origin, retrieval time, and confidence of a metadata or language claim.
- **Playback candidate:** A particular source/version that might be playable through a supported transport.
- **Provider registry:** The configured list of integrations, capabilities, lifecycle status, and constraints.
- **Source aggregation:** Combining different providers' options under one title while retaining each source association.
- **Universal search:** A single user query orchestrated across all eligible enabled providers.
